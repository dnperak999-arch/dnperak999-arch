# Data Science & Applied Analytics

I'm an MSc Data Science student in London, building practical projects across machine learning, data analysis, data pipelines, and relational databases.

I focus on reproducible workflows, explicit validation, and understanding the limitations behind a result — not just producing a model or visualisation.

## Selected projects

### [PAYE Mean Pay Forecasting](https://github.com/dnperak999-arch/paye-mean-pay-forecasting)
Time-based forecasting of UK PAYE mean pay with baseline comparison, model evaluation, and exploratory clustering.

**Python · pandas · scikit-learn · forecasting · clustering**

### [Air Quality Data Pipeline](https://github.com/dnperak999-arch/air-quality-data-pipeline)
Tested pipeline for cleaning, validating, and analysing cross-country air-quality data, including PCA and correlation analysis.

**Python · pandas · data validation · PCA · pytest**

### [Retail Supermarket Database](https://github.com/dnperak999-arch/retail-supermarket-database)
Relational retail database built with Python and SQLite, with integrity constraints, deterministic rebuilds, analytical queries, and automated tests.

**Python · SQL · SQLite · relational modelling · unittest**

### [Global Education Indicators](https://github.com/dnperak999-arch/global-education-indicators)
Reproducible analysis of international education indicators with explicit reporting-coverage checks, same-level metrics, and careful treatment of missing data.

**Python · pandas · data quality · visualisation · pytest**
